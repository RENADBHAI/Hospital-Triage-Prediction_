# Hospital-Triage-Prediction_
Hospital Triage Prediction is an end to end machine learning project developed using clinical data from King Abdullah University Hospital to support patient prioritization in emergency care. Due to the sensitive nature of healthcare data and patient privacy requirements the dataset source code and detailed implementation cannot be publicly shared.
